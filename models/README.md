# FruitVision AI model

The training pipeline creates the trained MobileNetV2 classifier as:

`models/best_model.keras`

The upgraded project uses ten fruit classes in this order:

`Apple`, `Banana`, `Grape`, `Kiwi`, `Lemon`, `Mango`, `Orange`, `Pineapple`, `Strawberry`, `Watermelon`.

## Automatic setup

From the repository root:

```bash
python scripts/prepare_dataset.py
python train.py
```

The preparation script downloads the public Fruits-360 dataset through KaggleHub and selects images for the ten project classes. The full source dataset is not stored in this repository.

The trained `.keras` files and `models/class_names.json` are generated by the training pipeline. GitHub Actions can also prepare the dataset, train the model, evaluate it, and publish the generated model and class metadata.
